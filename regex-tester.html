How to Use ToolNest Regex Tester

  1. Enter a pattern: Type your regular expression in the pattern field.
  2. Set flags: Toggle global, case-insensitive, multiline, or dotAll as needed.
  3. Paste test text: Add the sample text you want to match against.
  4. Review matches: Matches highlight inline, with a detailed list including any groups.

Frequently Asked Questions

What regex engine does this use?

It uses your browser's native JavaScript RegExp engine, so results match exactly what you'd get running the same pattern in JavaScript code.

Why aren't multiple matches highlighting?

Make sure the global (g) flag is enabled — without it, only the first match in the text is found.

Is my pattern or text sent to a server?

No. All matching happens entirely client-side in your browser.
