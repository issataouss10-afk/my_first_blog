Frequently Asked Questions

Does this decode URL-encoded characters?

Yes. Query parameter values are automatically decoded, so %20 shows as a space, for example.

Is my URL sent to a server?

No. Parsing runs entirely client-side in your browser for privacy and speed.

What if the URL has no query parameters?

The parameters table stays empty and a short note lets you know none were found.
