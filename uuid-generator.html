Frequently Asked Questions

What is a UUID used for?

UUIDs are commonly used as unique identifiers for database records, API resources, session tokens, and distributed systems where IDs need to be generated without a central authority.

What UUID version does this generate?

This tool generates version 4 (random) UUIDs, the most common type, based on cryptographically secure random numbers rather than timestamps or hardware identifiers.

Is my generated UUID sent to a server?

No. Every UUID is generated entirely client-side in your browser using the Web Crypto API.
