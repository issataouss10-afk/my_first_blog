Frequently Asked Questions

  

    

      Does this verify the token's signature?
      
No. Verifying a signature requires the secret or public key used to sign it, which this tool doesn't have. It only decodes the header and payload, which is always possible without any key.

    

    

      Why can I read the payload without a key?
      
A JWT's header and payload are base64url-encoded, not encrypted — encoding just changes the representation, so anyone can decode and read them. Only the signature is cryptographically protected.

    

    

      Is my token sent to a server?
      
No. All decoding happens entirely client-side in your browser.
