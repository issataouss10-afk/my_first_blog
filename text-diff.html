Frequently Asked Questions

Does this compare word-by-word or line-by-line?

This tool compares line by line — a line is marked as added or removed if it doesn't have an exact (or option-adjusted) match on the other side.

Can I use this to compare code?

Yes, it works well for comparing code snippets, config files, or any plain text — just watch for indentation differences unless you enable the whitespace option.

Is my text sent to a server?

No. The comparison runs entirely client-side in your browser.
