Frequently Asked Questions

Does this handle quoted values with commas inside?

Yes, values wrapped in double quotes can contain commas and are parsed correctly as a single field.

What happens without a header row?

If "First row is headers" is unchecked, keys are generated as column1, column2, and so on.

Is my data sent to a server?

No. All parsing happens entirely client-side in your browser.
